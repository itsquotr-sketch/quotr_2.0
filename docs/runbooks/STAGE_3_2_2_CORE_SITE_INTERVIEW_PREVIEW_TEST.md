## A. Deck

Project with known restricted/difficult access + 25–30m (or 10–30m) carry; balustrade excluded; demolition included.

**Expect:**

- Project Conditions does **not** re-ask access or carry
- May show Complete immediately if no other PROJECT asks remain
- Site Constraints summary shows known access/carry
- No duplicate Site Constraints questionnaire

## B. Bathroom

Project with one or more unknown project conditions.

**Expect:**

- Concise project-level questions (occupied / access / logistics) where engine says relevant
- Does **not** ask waterproofing, vanity, fixture, granular tiling (Scope Details)
- Batch Save answers once
- Site Constraints summary updates

## C. Commercial Fitout

7+ Work Areas.

**Expect:**

- Project logistics asked **once**
- No per-WA access clones in Project Conditions
- Granular items stay in Scope Details

## D. Conflict

Change an existing user-confirmed constraint via Project Conditions to a different value.

**Expect:**

- Keep existing / Use proposed confirmation
- No silent overwrite

## E. Batch

Answer 3 questions → Save once.

**Expect:**

- One save cycle
- Candidate count updates once
- No repeated refresh churn

## F. Quick Estimate

**Expect:**

- Project information readiness label shown
- Generate Estimate behaviour unchanged (no soft-block)

## G. Mobile (~390px)

**Expect:**

- Full width, no horizontal scroll
- h-11 tap targets
- Save answers visible
- One-tap yes/no/options where applicable
